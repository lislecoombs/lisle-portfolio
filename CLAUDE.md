# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Working with Lisle

- Lisle is new to coding — explain concepts clearly and avoid assuming prior knowledge. When writing or editing code, briefly explain what changed and why in plain English.
- Ask for clarification whenever a request is ambiguous or needs more detail before proceeding. If a task requires information you don't have (an image, a specific file, a decision from Lisle), pause and ask rather than working around it.
- If a task is very large or complex, offer less labour-intensive alternatives, or ask Lisle to handle a part of it (e.g. generating an image, writing copy) to make it more manageable.
- If unsure how to do something, say so rather than guessing and producing broken code.
- Do not refactor or "improve" things that weren't asked about.
